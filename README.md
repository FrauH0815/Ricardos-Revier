# Ricardos-Revier

Interaktive 3D-Werkstatt für Ricardo, fürs Handy gebaut (three.js, GitHub Pages).

- `index.html` – die Werkstatt zum Durchlaufen. Drinnen öffnet der Knopf „🎮 SPIELE“ die Spiele auf dem Fernseher, gewonnene Trophäen stehen als Pokale im Trophäenschrank.
- `games/angeln.html` – Angeln: Dorfteich, großer See, Fluss am Abend
- `games/kegeln.html` – Kegeln/Bowling mit Physik: Übungsbahn, Vereinsabend, Spare-Challenge, Meisterschaft
- `games/jagd.html` – Jagd vom Hochsitz: Schießstand, Lichtung, Dämmerung, Nebel

Fortschritt und Trophäen liegen im Browser (localStorage, Schlüssel `rr_…`). Quellen und Lizenzen der Modelle: `assets/sources.json`.
